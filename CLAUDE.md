# AtlasOS — заметки для агентов

Образ ОС в духе macOS поверх Bazzite KDE, собирается BlueBuild'ом в GitHub Actions.
Как устроены сборка, тестовая ВМ и цикл «правка → проверка» — в `docs/DEV.md`. Прочитай его перед работой.

- Проверять изменения в ВМ: `scripts/vm.sh` (sync / try / check). Команды в ВМ — по `ssh atlasvm`.
- Всё, что меняет систему, — в `recipes/common.yml` и `files/system/`, а не в `recipe-*.yml` (общее для AMD/Intel и NVIDIA).
- Секреты подписи (`cosign.key`) в репозиторий не класть.
- В `main` напрямую не пушить без слова владельца; работать в ветке и проверять её сборку в ВМ.
