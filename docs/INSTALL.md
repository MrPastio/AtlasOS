# Установка AtlasOS

Основной путь — свой ISO: `atlasos-nvidia-live-amd64.iso` для NVIDIA,
`atlasos-live-amd64.iso` для AMD/Intel. Его можно положить на флешку Ventoy.

## С ISO

1. **Резервная копия.** Перед установкой рядом с Windows сохраните важное.
2. **Загрузка.** Загрузитесь с флешки в режиме UEFI и выберите «Install AtlasOS». Если экран чёрный —
   второй пункт, Basic Graphics Mode.
3. **Разметка рядом с Windows.** Освободите место заранее, в установщике выберите ручную разметку
   и создайте **новый** EFI-раздел на 1 ГБ (`/boot/efi`), `/boot` и корень в свободном месте.
   Старый EFI-раздел не используйте, если он маленький или на нём есть GRUB другого Linux:
   установка рядом с чужим GRUB падает на `grub2-mkconfig`. Раздел Windows и её загрузчик остаются как есть.
4. **Первый вход.** Система уже на подписанном образе. Откроется «Добро пожаловать».
   Перенести проекты и память Claude Code: команда из шага 3 ниже.

Выбрать Windows можно в меню загрузки компьютера или в GRUB, если он её нашёл.

## Через Bazzite

Если ISO нет под рукой: ставится официальный Bazzite, затем система переключается (rebase) на образ
AtlasOS. Файлы и настройки при переключении не трогаются, прежняя версия остаётся в меню загрузки.

## Какой образ

| Видеокарта | Bazzite для установки | Образ AtlasOS |
| --- | --- | --- |
| NVIDIA RTX / GTX 16xx | Bazzite KDE, NVIDIA | `ghcr.io/mrpastio/atlasos-nvidia` |
| AMD / Intel | Bazzite KDE | `ghcr.io/mrpastio/atlasos` |

## Шаги

1. **Резервная копия.** Перед установкой рядом с Windows сохраните важное — разметка диска
   единственный шаг, где можно что-то потерять.
2. **Bazzite.** Скачайте ISO с bazzite.gg (KDE, нужный вариант видеокарты), запишите на флешку,
   установите. Рядом с Windows — выберите свободное место на диске, а не весь диск.
   Secure Boot: при первом запуске Bazzite попросит подтвердить свой ключ (MOK) — пароль
   `universalblue`.
3. **Переключение на AtlasOS.** В Konsole на чистом Bazzite:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/MrPastio/AtlasOS/main/scripts/install.sh | bash
   ```

   Скрипт сам выберет образ по видеокарте и дважды перезагрузит систему: Bazzite ещё не знает
   ключа подписи Атласа, поэтому первый раз образ ставится без проверки подписи, второй — уже
   с ней (ключ приезжает вместе с образом). После каждого входа он продолжает сам в окне Konsole;
   нужно только ввести пароль. Если прервать, запустить снова: `~/.local/bin/atlas-install`.
4. **Работа.** На последнем шаге скрипт попросит войти в GitHub (код и браузер), потом разложит
   проекты в `~/Projects`, вернёт память и навыки Claude Code из приватного `claude-memory`
   и поставит сам Claude Code. Войти в него: `claude` из папки проекта.
5. **Первый вход.** Откроется «Добро пожаловать»: оформление и приложения (Claude, Discord,
   Telegram, OBS…). Окно можно открыть снова из Компаса.

## Дальше

- Обновления ставятся сами раз в день; вручную и откат — «Обновление системы» в Компасе.
- Claude Desktop живёт в контейнере distrobox `claude` (официальная сборка только для Ubuntu/Debian):
  `atlas-claude install | update | status`.
- Если Claude показывает чёрное окно — он ждёт KDE Wallet: введите пароль в его запросе.

## Как переносится работа

Шаг 4 установки берёт каждый проект из архива памяти (`E--Имя`) и кладёт в `~/Projects/Имя`:
код клонируется из `MrPastio/Имя`, если такой репозиторий есть, а память — под ключ нового пути.
Если репозитория нет, ложится только память; код нужно перенести в эту папку вручную.
Скрипт покажет такие проекты в конце. Запустить этот шаг снова: `~/.local/bin/atlas-install`.
